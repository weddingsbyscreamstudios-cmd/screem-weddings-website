# Website

The Screem Weddings Productions website (DL-033). **Status: proposed (preview only, not published).**

## Files
| File | What it is |
|---|---|
| `index.html` | The whole site: hero, films, services, how it works, packages, about, FAQ, enquiry |
| `styles.css` | Look and layout (minimal, white + light green) |
| `script.js` | Menu, scroll animations, enquiry form (not connected yet) |
| `404.html` | "Page not found" page |
| `assets/fonts/` | Cormorant Garamond + Inter, SIL OFL 1.1 (licence files included) |
| `assets/favicon.svg` | Browser-tab icon (temporary "S" mark) |
| `netlify.toml` | Netlify settings, used only once publishing is approved |
