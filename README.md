# Website

The Screem Weddings Productions website (DL-033, DL-034). **Status: live on GitHub Pages with placeholder content.**

- Live site: https://weddingsbyscreamstudios-cmd.github.io/screem-weddings-website/
- Repository (public): https://github.com/weddingsbyscreamstudios-cmd/screem-weddings-website

## Files
| File | What it is |
|---|---|
| `index.html` | The whole site: hero, films, services, how it works, packages, about, FAQ, enquiry |
| `styles.css` | Look and layout (minimal, white + light green) |
| `script.js` | Menu, scroll animations, gallery "show more", enquiry form (emails via Web3Forms, DL-037) |
| `404.html` | "Page not found" page |
| `assets/fonts/` | Cormorant Garamond + Inter, SIL OFL 1.1 (licence files included) |
| `assets/favicon.svg` | Browser-tab icon (temporary "S" mark) |
| `netlify.toml` | Netlify settings, used only once publishing is approved |

## Before it can go live
Anything shown in *green italic [brackets]* or "placeholder" is waiting for a decision (open decisions D-16 to D-21):
1. Packages: names, contents, prices (D-16)
2. Films and photos: only with couple consent and cleared music (D-17)
3. Contact details and WhatsApp button (D-18; form email done, DL-037)
4. Privacy notice (D-19)
5. Domain and Netlify account (D-20)
6. Remove the green "Preview" banner at the top of `index.html`

Every push to GitHub updates the live site within a minute.
